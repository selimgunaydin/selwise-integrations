{# Selwise — order tracking for the Project Zero (Django) success page ================================================================== Install ------- Copy to `templates/orders/selwise-order.html` and include it at the bottom of the checkout success template (usually `templates/orders/success.html` or the project's `checkoutSuccess` page): {% include "orders/selwise-order.html" %} Why this is needed even though the shim already forwards `purchase` ------------------------------------------------------------------ The Enhanced Ecommerce shim maps `ecommerce.purchase` to a GA4 `purchase` event, and Selwise's data-layer bridge does create an order from it. That path is fine, but it inherits whatever the EE payload happens to contain — and PZ's `orderCompleted` payload varies per project. `trackOrder` is the explicit path: it names the order id, the total and the line items, and it is idempotent on the order id, so a customer refreshing the thank-you page cannot create a second order. Campaign and widget revenue reporting is built on these rows, so the explicit call is worth the ten lines. Both paths together do NOT double-count: the server keys on `orderId`. Identity -------- `productItemCode` MUST be the same value the product feed carries as `item_code`. In most Akinon projects that is the variant `sku`. Confirm it once against the feed — a mismatch does not error, it silently files the revenue against an unknown product. #}
